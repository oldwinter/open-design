# Pricing — Open Design

Open Design 是**免费且开源**的。桌面应用（macOS、Windows、Linux）采用
Apache-2.0 许可，并支持 BYOK：你可以免费安装，只为自己的 agent/model API
用量付费，费用直接结算到你自己的 provider account。Open Design 不会中转这些请求。

可选付费套餐提供 **managed** 体验：内含模型用量额度（因此不需要自备 key）以及托管云端部署。它们是可选项，不是使用 Open Design 的前提。

## Free — 开源桌面应用
- Price：**$0 / month，永久**
- License：Apache-2.0（完整源码见 https://github.com/nexu-io/open-design）
- Model access：**BYOK**，使用你自己的 provider key；API 用量结算到你自己的账号，绝不经由 Open Design 代理
- Runs：local-first，运行在你自己的机器上（macOS、Windows、Linux）
- Includes：完整 skill + design-system library、所有受支持的 coding agent（Claude Code、Codex、Cursor、Gemini、OpenCode、Qwen 等），以及以文件形式保存在你自己 repository 中的 artifacts
- Get it：https://open-design.ai/download/

## Plus — managed
- Price：**$20 / month**（或 $168 / year，30% off）
- Included model usage credits：$20 / month
- Cloud deploys：最多 3 次 / month
- For：偏好 bundled credits 而非 BYOK 的个人用户

## Pro — managed（recommended）
- Price：**$100 / month**（或 $720 / year，40% off）
- Included model usage credits：$100 / month
- Cloud deploys：最多 20 次 / month
- For：定期 shipping 的专业用户

## Max — managed
- Price：**$200 / month**（或 $1,176 / year，51% off）
- Included model usage credits：$200 / month
- Cloud deploys：最多 50 次 / month
- For：重度用户和 teams

## Notes
- 开源桌面应用始终免费；付费套餐是可选 managed service（bundled model credits + hosted cloud deploys），不是使用 Open Design 的必要条件。
- 超出套餐月度额度的 cloud deploys：每次 $2。
- Intro/promotional pricing 和当前 annual discounts 可能不同；最新数字以实时 pricing page 为准：https://open-design.ai/pricing/
